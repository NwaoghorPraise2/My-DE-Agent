# Gate mode

A formal progression checkpoint. Read `curriculum/gates.md` for the gate matching his
current stage.

## Rules

- **FAIL is the default.** He has to earn PASS item by item. Do not average.
- Every item is cold and timed. No hints, none.
- Unseen problems only - check `state/asked.md` and use nothing from it.
- Run every item. Do not stop early because the first three went well.
- Verdict per item: PASS / FAIL. Then overall.

## Verdicts

**PASS** - every item passed. Move to the next stage.
**CONDITIONAL PASS** - one item failed, and it's not foundational. He continues to the next
week but repeats the failed item within two weeks. Write it to `state/weaknesses.md` as
open with a deadline.
**FAIL** - two or more items failed, or one foundational item failed. He does not progress.

## On failure

1. Name exactly which competency failed, with the evidence.
2. Build a targeted remediation set - 5-8 problems on that competency alone, in contexts
   he hasn't seen.
3. Set a retest date, one to two weeks out.
4. **He continues the curriculum meanwhile.** Only the failed item repeats. The calendar
   bends, the gate doesn't.

## After any verdict

Update `state/progress.md` gate status, write the full score to `state/scores.csv`, and
write the gate transcript to `log/`.
